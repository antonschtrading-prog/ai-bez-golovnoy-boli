# ИИ без головной боли

Учебные материалы A1–C1 и локальное приложение. Публичный сайт: https://antonschtrading-prog.github.io/ai-bez-golovnoy-boli/.

## Состояние разработки

Облачной синхронизации и входа в аккаунт на сайте **нет**. Подготовлены и протестированы локальный серверный API и Cloudflare Workers + D1 (включая тестовый вход через Telegram Mini App и OIDC). Настоящие Cloudflare/Telegram-аккаунты ещё не настроены, сервер не развёрнут, а веб-интерфейс к API не подключён.

- `recovery.html`: история и восстановление раздела; подготовка миграции без перезаписи прогресса.
- `progress-storage.js`: прежние localStorage-ключи + отдельные снимки.
- `progress-migrations.js`: совместимые копии v1/v2 и экспорт основного курса v3–v5.
- `server/`: Node.js 24 + встроенный SQLite, без платных сервисов.

## Проверка

Node.js 24. `npm ci`, затем `npm test`. Для браузерных тестов: `npx playwright install --with-deps chromium`, `npm run test:browser`. Можно задать `CHROMIUM_PATH`. Тесты поднимают собственные HTTP-серверы и используют только вымышленные данные. Тестовая SQLite-база удаляется после проверки. GitHub Actions запускает обе группы.

`npm run start:api` запускает подготовительный сервер только на 127.0.0.1:8787. Все запросы требуют сессию; публичной регистрации и тестового обхода авторизации нет. Не выставлять этот сервер в интернет без выполнения списка готовности в документации.
