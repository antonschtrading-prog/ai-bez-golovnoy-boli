# Автоматическая проверка практики: подготовленный защищённый контур

## Текущее состояние

В коде существует **неактивный по умолчанию** endpoint `POST /v1/review` на **существующем** Worker `ai-course-progress`. Код и автотесты сами по себе **не включают** доступ к платной модели и не доказывают готовность production-оценивания. Кнопки в `assessment.html` и `deep-practice.html` вызывают сервер **только по нажатию**, из авторизованной Telegram Mini App, с передачей текста текущей работы. В обычном браузере без Telegram OIDC кнопка сообщает об отсутствии авторизации.

Для реального запуска необходимо отдельно настроить привязки Workers AI и Rate Limiting в **уже существующем Worker**, выбрать доступную в аккаунте модель, оценить стоимость и ограничения квоты, провести тест на реальных устройствах и лишь затем включить `AI_REVIEW_ENABLED=true`. Никаких новых Workers/D1/ботов создавать не нужно.

## Безопасность и ограничения

- Запрос принимает только HTTPS origin, разрешённый в `COURSE_ORIGINS`, и действующую серверную сессию пользователя Telegram. Заголовок `Authorization` не принимается из параметров URL.
- Нет сетевого вызова к модели, если **одновременно** не настроены `AI`, `AI_REVIEW_LIMITER`, `AI_REVIEW_MODEL` и флаг `AI_REVIEW_ENABLED=true`. В этом случае ответ 503 `review_not_configured`.
- Проверка ограничена длиной работы до 12 000 символов, количеством критериев 1–8 и `max_tokens=1250`. Cloudflare Rate Limiting вызывается по идентификатору серверного аккаунта, до запроса к модели; 429 при превышении. Этот limiter работает по местоположениям Cloudflare и **не является абсолютным глобальным бюджетом**. Для массового запуска дополнительно установите лимиты расходов/квоты на стороне Cloudflare.
- Ответ модели обязан соответствовать `course-rubric-review-v1`, включать все критерии ровно один раз и цитировать **буквальные подстроки ученической работы** для положительного/частичного вывода. Неверный ответ возвращает 502 `review_unavailable`. Это проверка наличия цитаты, а не истинности утверждений или качества рассуждения.
- Вводимый учеником текст считается недоверенными данными, инструкции внутри не исполняются. На странице отзыв отображается как рекомендация с экранированием HTML, а не как сертификат. После редактирования черновика прежний отзыв отмечается устаревшим.
- Полный отчёт и локальные черновики **не отправляются автоматически**. Сервер не записывает результат оценки в D1; успешный клиент сохраняет результат в прежний раздел прогресса, который далее синхронизируется обычным способом.
- Прежде чем включать сервис для других пользователей, подтвердите обработку и сроки хранения отправленных работ у выбранной модели и подготовьте понятное уведомление о передаче их третьей стороне. Не отправляйте секреты и персональные документы.

## Настройка — только после согласования

В конфигурации *существующего* Worker, без дублирования ресурсов:

```toml
[ai]
binding = "AI"

[[ratelimits]]
name = "AI_REVIEW_LIMITER"
namespace_id = "1001" # Заменить на собственный namespace ID
[ratelimits.simple]
limit = 2
period = 60

[vars]
# сохранить существующий COURSE_ORIGINS и другие значения!
AI_REVIEW_MODEL = "@cf/SELECT_A_SUPPORTED_TEXT_MODEL"
AI_REVIEW_ENABLED = "true"
```

Этот фрагмент следует **объединить** с текущей конфигурацией, а не перезаписывать `[vars]` целиком. `SELECT_A_SUPPORTED_TEXT_MODEL` — заглушка, её нельзя отправлять в производство. Проверить поддерживаемый формат `messages` и ограничения выбранной модели. Включать флаг только после тестов, оценки реальных расходов и явного решения владельца.

Источник конфигурации: https://developers.cloudflare.com/workers-ai/get-started/workers-wrangler/ и https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/.

## Проверка перед включением

`npm test` — вход, CORS, лимиты, валидация текста, цитат, отсутствие ложного зачёта, ограничение запросов; `npm run test:browser` — совместимость интерфейса, сохранение ответов, показ доступности и ошибок. После настройки настоящей модели: проверка минимум на 20 эталонных работах (хорошие, слабые, противоречивые, короткие, с ложными источниками и попытками prompt injection), оценка согласованности с независимой человеческой рубрикой, сравнение затрат и ошибок отказа. Пока эта калибровка не проведена, нельзя выставлять финальные оценки.
