# Выгрузка резервной копии облачного восстановления

После успешного восстановления на странице аккаунта можно просмотреть и скачать локальные резервные копии. Список показывается **только для проверенного Telegram-аккаунта**. Запись резервной копии сохраняет все исходные значения семи разделов, включая незавершённые задания, а также ревизию и время. JSON-файл содержит личные учебные ответы и не шифруется.

Действия пользователя: войти → «Показать резервные копии» → выбрать копию → «Скачать выбранную копию». Ни при чтении списка, ни при экспорте сетевые запросы не отправляются.

Файлы проверяются на формат и валидность каждого раздела. Копия другого аккаунта не может быть выбрана через этот интерфейс. Повреждённые копии не переписываются и не удаляются автоматически.

Это экспорт, **не автоматический импорт из файла**. Для полной аварийной процедуры восстановления потребуется отдельная проверенная функция ручного восстановления из резервной копии либо пораздельная история на странице `recovery.html`.
