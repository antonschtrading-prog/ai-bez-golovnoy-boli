# Один жизненный цикл аккаунта и блокировка операций

Исправлено расхождение между Mini App и обычным браузерным входом Telegram: оба способа после успешной серверной аутентификации подключают одинаковые модули очереди, восстановления из облака, экспорта резервных копий и восстановления из файла. Выход из аккаунта и уход со страницы очищают все временные подтверждения и токен в памяти, но не удаляют данные курса.

Модули `CourseAccountOutboxController`, `CourseCloudRestore` и `CourseFileRecovery` используют единое имя Web Lock `course-sync-account:<verifiedAccountId>`. Поэтому операции над локальным прогрессом в **этих трёх интерфейсах** не конкурируют друг с другом в разных вкладках на одном origin. Сервер продолжает проверять ревизии и идемпотентность.

Важно: другие локальные страницы курса пока могут сохранять данные без этого Web Lock, поэтому проверка исходных значений непосредственно перед записью обязательна; нельзя объявлять строгую глобальную транзакционность, а при переносе лучше закрыть параллельные вкладки занятий. Фоновая синхронизация и использование реальных учётных данных без настройки Telegram по-прежнему отключены.
