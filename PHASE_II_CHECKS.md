# Фаза II — технические проверки и открытые задачи

Дата: 10 ноября 2026 года.

## Выполненные изменения

1. Добавлена общая адаптивная навигация из девяти разделов в файле `course-nav.js`; подключена ко всем девяти HTML-страницам.
2. Убраны восемь дублирующих ссылок из шапки основного курса; оставлена главная кнопка персонального плана.
3. Исправлено устаревшее описание количества углублённых занятий и требование пользоваться только ChatGPT.
4. Экспорт полной резервной копии прекращается при некорректной JSON-записи; больше не создаётся заведомо неполная копия под обычным именем.
5. Восстановление проверяет формат копии, допустимые ключи и базовую структуру каждого раздела; операция требует согласия и пытается откатить данные, если сохранение не удалось.
6. С экрана маршрута доступна автоматическая диагностика записи в браузер и повреждённых JSON-записей.
7. Разъяснено, что резервная копия из главного курса охватывает только его собственные данные; общая копия находится на экране маршрута.

## Проверки, реально выполненные средствами JavaScript

- Создание резервной копии с корректной записью — файл инициирован, сообщение о результате показано.
- Попытка экспорта повреждённой JSON-записи — создание файла отменено.
- Попытка экспорта при отсутствии результатов — создание пустой копии отменено.
- Восстановление валидного файла — запись обновлена.
- Восстановление файла с неверной структурой — отклонено без изменения старой записи.
- Ошибка при записи в хранилище — восстановление отклонено, исходное значение в тестовом сценарии сохранено.
- Проверка локального хранилища: пустые, корректные, повреждённые и недоступные для записи данные — все четыре ветки выдают соответствующий статус.
- Генерация общего меню на странице оценки — девять относительных ссылок, текущий раздел отмечен как активный.

Эти проверки выполнены в моделируемой среде исполнения JavaScript с искусственными `document` и `localStorage`. Они подтверждают конкретную логику обработчиков, но **не** доказывают, что пользовательский интерфейс работает на реальном устройстве.

## Что пока НЕ проверено

- Сквозное прохождение занятия в реальном Chromium и Safari с сохранением данных после закрытия и повторного открытия.
- Публичная публикация новой версии, включая работу общего подключаемого файла `course-nav.js`.
- Настоящее скачивание JSON на iPhone и последующее восстановление из приложения «Файлы».
- Отображение на iPhone в портретной и горизонтальной ориентации; доступность для экранных дикторов.
- Миграция разных реально накопленных вариантов старых сохранений.
- Конфликты данных при самостоятельном переносе между устройствами; настоящая облачная синхронизация относится к третьей фазе.

Для проверки вкладок браузера требуется контекст подключённого браузера; в данной сессии он не доступен. Публичный адрес GitHub Pages также не удалось открыть из используемой среды. Эти ограничения нельзя подменять заявлением «проверено в браузере».

## Условия закрытия второй фазы

1. Все базовые пользовательские сценарии действительно выполняются в рабочем браузере.
2. Резервные копии создаются, скачиваются, импортируются и читаются после перезагрузки.
3. Навигация и основной контент пригодны для мобильного экрана, клавиатуры и экранного диктора.
4. Предыдущие сохранения продолжают корректно открываться после обновления.
5. Исправлены критические ошибки, выявленные реальными испытаниями.

**Текущий статус:** часть второй фазы реализована и проверена на уровне кода; фаза не может считаться завершённой без настоящих браузерных испытаний.
